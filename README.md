# Bài Tập: Sử Dụng Thẻ Hình Ảnh Trong HTML (HTML Images)

Bài tập thực hành chèn hình ảnh bằng thẻ tự đóng `<img>` trong HTML5, bao gồm các thuộc tính quan trọng:
- `src`: Đường dẫn hình ảnh (online hoặc nội bộ).
- `alt`: Đoạn văn bản thay thế mô tả bức ảnh (bắt buộc cho SEO và trợ năng).
- `width`/`height`: Kích thước hiển thị cân đối của bức ảnh.

## 🚀 Cách mở xem
Mở trực tiếp tệp [`index.html`](index.html) bằng trình duyệt web bất kỳ (Chrome, Edge, Firefox,...).
